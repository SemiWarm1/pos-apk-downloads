# POS APK 下载

本仓库用于发布 Android APK 安装包。

## 下载

请前往 [版本发布页面](https://github.com/SemiWarm1/pos-apk-downloads/releases) 下载对应版本的 `.apk` 文件。

## 待发布版本

- 状态：等待上传发布；当前尚未提供 APK 下载。
- 类型：测试预发布版本

## 发布方法

1. 在 Releases 页面点击 **Draft a new release**。
2. 新建标签 `v0.2.2-beta.2-test`，标题填写 `RMP 0.2.2-beta.2-test`。
3. 将 `RMP-0.2.2-beta.2-test.apk` 拖入附件区域，等待上传完成。
4. 勾选 **Set as a pre-release**，点击 **Publish release**。

发布完成后，可将对应版本的发布页面链接分享给其他人下载。
